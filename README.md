# Number Guessing Game

A Bash-based number guessing game that uses PostgreSQL to store player statistics.

## Features

- Generates a random number between 1 and 1000.
- Provides higher and lower hints.
- Validates user input.
- Tracks the number of games played.
- Records each player's best game.
- Welcomes returning players with their statistics.

## Requirements

- Bash
- PostgreSQL
- Git

## How to Run

Make the script executable:

```bash
chmod +x number_guess.sh
